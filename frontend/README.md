# PDF AI - Frontend

The user interface for the PDF AI application, built with React and Vite.

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```

## 🎨 Features
- **Modern Glassmorphism Design**: High-end aesthetic with dark mode and blurs.
- **Responsive Layout**: Works seamlessly on mobile and desktop.
- **Real-time Processing**: Visual feedback for file uploads and AI thinking states.
- **Secure Key Handling**: Users can provide their own Gemini API key in the UI.

## 📁 Structure
- `src/components`: Reusable UI components.
- `src/App.jsx`: Main application logic and state management.
- `src/index.css`: Global styles and Tailwind configuration.
